# Actual Classic

A YNAB4-inspired dark theme for [Actual Budget](https://actualbudget.org), built to make the budget page easy to scan.

It starts from [You Need A - Theme! Dark](https://github.com/Juulz/YNA-Theme-Dark) by Juulz and changes:

- **Zero amounts are greyed out**, so real numbers stand out.
- **Row lines are quieter**, so group rows and months stand out.
- **Months get a clearer divider** on the budget page.
- **Positive balances are green.**

## Install

In Actual, open **Settings > Themes**, choose to install a custom theme and pick **Actual Classic** from the catalog. If your version of Actual doesn't list it, paste the contents of `actual.css` into the **Additional CSS overrides** box instead.
